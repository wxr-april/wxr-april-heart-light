                <p><strong>安溪第三中学</strong>创办于1958年，迄今已有六十余年的办学历史。学校坐落于安溪县城区中心，地理位置优越，交通便利。校园占地约120亩，建筑面积约4.2万平方米，绿化覆盖率达35%以上，是一所环境优美、设施完善的完全中学。</p>

                <p style="text-indent:0;font-weight:600;color:#1a3a6a;margin-top:10px;">校训</p>
                <p>厚德 博学 笃行 致远</p>

                <p style="text-indent:0;font-weight:600;color:#1a3a6a;margin-top:10px;">办学理念</p>
                <p>立德树人、全面发展</p>

                <p style="text-indent:0;font-weight:600;color:#1a3a6a;margin-top:10px;">办学目标</p>
                <p>建设成为安溪县乃至泉州市有影响力、有特色的优质完全中学</p>

                <p style="text-indent:0;font-weight:600;color:#1a3a6a;margin-top:10px;">校园环境</p>
                <p>学校校园布局合理，教学区、运动区、生活区分明。校内绿树成荫，环境幽雅。建有标准化田径运动场、多功能报告厅、图书馆（藏书近8万册）、理生化实验室、信息技术教室、心理咨询室等教学设施，为学生提供了良好的学习和成长环境。</p>

                <p style="text-indent:0;font-weight:600;color:#1a3a6a;margin-top:10px;">生活设施</p>
                <p>学校食堂、学生公寓等生活设施齐全，实行封闭式管理，为住校生提供了安全、舒适的生活条件。学校高度重视校园安全，建立健全了安全管理体系，连续多年被评为"安溪县平安校园"。</p>

                <p style="text-indent:0;font-weight:600;color:#1a3a6a;margin-top:10px;">办学成果</p>
                <p>学校先后荣获"福建省义务教育管理标准化学校""安溪县文明校园""安溪县教育教学先进单位"等荣誉称号。近年来，学校在学科竞赛、体育比赛、艺术展演等方面取得了丰硕成果。</p>

        function switchPage(pageId) {
            Object.keys(pageSections).forEach(function(key) {
                pageSections[key].classList.remove('active');
            });
            if (pageSections[pageId]) {
                pageSections[pageId].classList.add('active');
            }
            navLinks.forEach(function(link) {
                link.classList.remove('active');
                if (link.dataset.page === pageId) {
                    link.classList.add('active');
                }
            });
            window.scrollTo({ top: 0, behavior: 'smooth' });
        }

        navLinks.forEach(function(link) {
            link.addEventListener('click', function(e) {
                e.preventDefault();
                var page = this.dataset.page;
                if (page) switchPage(page);
            });
        });

        window.switchPage = switchPage;
