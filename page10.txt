                            <p>安溪县数字档案馆于2008年正式上线，是安溪县档案局面向社会公众提供数字档案查询服务的官方平台。本馆馆藏涵盖1920年至今的各类地方报纸、县志、人口登记、土地契税、教育档案、商会史料、宗教记录、宗族谱牒、民间契约、碑刻拓片等数字资源，共计约12万册（件），是研究安溪地方历史、民俗文化、社会发展的重要文献基地。</p>
                            <p>本馆依托先进的数字扫描与OCR识别技术，将大量珍贵历史文献进行数字化保存。截至目前，已完成对安溪县内主要寺院、道观、宗祠等场所现存碑刻、匾额、钟铭等文物文字资料的数字化采集与整理工作，其中尤以青元山道观所藏明代铜油灯铭文、清代木刻经版、民国时期道教法器等方面的记录较为完整，共计收录条目四百余件，时间跨度从明万历年间一直延续至二十世纪中叶。</p>
                            <p>本馆面向社会免费开放查询服务，支持按年份、人名、地名、关键词等多种方式检索。所藏档案以原始文献扫描件为主，部分年代较近的档案亦提供可检索的电子文本。欢迎社会各界人士前来查阅，也欢迎热心市民向本馆捐赠或提供相关档案线索。</p>
                            <p>本馆重视地方历史文献的系统性收集与保护工作，近年来先后完成了《安溪县志》历代刊本的数字化整理、安溪籍华侨华人档案汇编、安溪老照片数字化修复等专题项目。馆藏中尤以民国时期安溪县商会档案、解放初期土地改革文书、以及各乡镇宗族谱牒等材料最具地方特色，为研究安溪近代社会变迁、宗族组织、商业发展等提供了极为珍贵的第一手资料。</p>
                            <p>在数字档案利用方面，本馆已建立完善的档案检索与调阅系统，读者可通过互联网远程查询馆藏目录，提交档案查阅申请。馆内同时设有电子阅览室，提供高清扫描件在线阅读、历史文献数据库检索等配套服务。本馆积极参与福建省档案数字化共建共享工程，与省内多家档案馆建立了数字资源互通机制，进一步拓展了档案信息的覆盖范围与服务能力。</p>

                        <div class="gazetteer-content">
                            <div class="gz-title">📜 安溪县志 · 卷一</div>
                            <div class="gz-body">
                                <p>安溪，位于福建省东南部，晋江上游，置县于后周显德二年（公元955年），迄今已历千余年。县境内地势自西北向东南倾斜，群山环抱，溪流纵横，安溪之名即源于此——溪流两岸安详宁静，水清如镜，寓"安居乐业、溪流清远"之意。</p>
                                <p>安溪素有"闽南茶都"之称，安溪铁观音茶自清代以来便名扬海内外，是中国十大名茶之一。安溪境内茶园广布，尤以感德、祥华、西坪、虎邱等乡镇所产铁观音最为著名。每年春、秋两季，茶香弥漫全县，外地茶商云集，市场交易极为活跃。除铁观音外，安溪亦产黄金桂、本山、毛蟹等乌龙茶品种，以及柿饼、麻粩、米粉等地方特产，皆远近闻名。</p>
                                <p>安溪人文荟萃，历代人才辈出。明万历年间，安溪学子陈砚秋秋闱登榜，名动一时；清乾隆年间，李光地入阁为相，位列上书房大臣；近代以来，安溪更是著名的侨乡和台胞祖籍地之一，海内外安溪籍乡亲逾百万人，分布于东南亚、欧美等二十余个国家和地区。安溪籍华侨热心桑梓，捐资助学、修桥铺路，为家乡发展做出了重要贡献。</p>
                                <p>安溪境内名胜古迹众多，有清水岩、安溪文庙、青元山道观、雁塔、东岳庙等。其中清水岩始建于北宋，依山而建，崖壁雕刻精美，是闽南著名佛教圣地；安溪文庙始建于宋，现存建筑为清代重修，规制完整，是全省保存较为完好的县级文庙之一；青元山道观始建于明万历三十八年，是安溪乃至闽南地区重要的道教活动场所，历经四百余年香火不断。道观依青元山势而建，三进院落层层递进，飞檐斗拱、雕梁画栋，主供三清道祖、玉皇大帝、天上圣母妈祖、保生大帝、文昌帝君等诸神。</p>
                                <p>安溪物产丰富，除茶叶外，藤铁工艺亦是安溪的重要产业。安溪是全国著名的藤铁工艺之乡，藤铁工艺品远销海内外数十个国家和地区，年产值逾百亿元。此外，安溪的竹编、木雕、陶瓷等传统手工艺也历史悠久，技艺精湛。</p>
                                <p>安溪民俗文化丰富多彩，有茶艺表演、高甲戏、布袋戏、南音、拍胸舞等。每年农历三月三、九月九，各地庙会、社戏不断，尤以清水岩庙会、青元山道观庙会最为盛大。安溪饮食文化也别具一格，以茶入菜、以茶佐餐，形成了独特的"茶宴"风格，湖头米粉、官桥豆干、龙涓肉羹等地方小吃亦深受食客喜爱。</p>
                                <p class="gz-sign">—— 《安溪县志》卷一 · 总叙 · 据清乾隆二十二年刊本整理 ——</p>

        // 1. 年份切换
        // =============================================================
        var yearBtns = document.querySelectorAll('.year-btn');
        var newspapers = document.querySelectorAll('.newspaper');

        function switchYear(year) {
            newspapers.forEach(function(n) {
                n.classList.remove('active');
            });
            var target = document.querySelector('.newspaper[data-year="' + year + '"]');
            if (target) {
                target.classList.add('active');
            }
            yearBtns.forEach(function(btn) {
                btn.classList.remove('active');
                if (btn.dataset.year === year) {
                    btn.classList.add('active');
                }
            });
        }

        yearBtns.forEach(function(btn) {
            btn.addEventListener('click', function() {
                var newspaperPage = document.getElementById('page-newspaper');
                var pages = document.querySelectorAll('.page');
                pages.forEach(function(p) { p.classList.remove('active'); });
                newspaperPage.classList.add('active');
                document.querySelectorAll('.nav a').forEach(function(a) {
                    a.classList.remove('active');
                    if (a.dataset.page === 'newspaper') a.classList.add('active');
                });
                switchYear(this.dataset.year);
            });
        });

        // =============================================================
        // 2. 导航切换
        // =============================================================
        var navLinks = document.querySelectorAll('.nav a');
        var pages = {
            home: document.getElementById('page-home'),
            catalog: document.getElementById('page-catalog'),
            gazetteer: document.getElementById('page-gazetteer'),
            newspaper: document.getElementById('page-newspaper'),
            contact: document.getElementById('page-contact')
        };
        var yearSidebar = document.getElementById('yearSidebar');

        function switchPage(pageId) {
            Object.keys(pages).forEach(function(key) {
                pages[key].classList.remove('active');
            });
            if (pages[pageId]) {
                pages[pageId].classList.add('active');
            }
            navLinks.forEach(function(link) {
                link.classList.remove('active');
                if (link.dataset.page === pageId) {
                    link.classList.add('active');
                }
            });

            // 年份侧边栏只在报纸库页面显示
            if (pageId === 'newspaper') {
                yearSidebar.style.display = 'block';
            } else {
                yearSidebar.style.display = 'none';
            }

            window.scrollTo({ top: 0, behavior: 'smooth' });
        }

        navLinks.forEach(function(link) {
            link.addEventListener('click', function(e) {
                e.preventDefault();
                var page = this.dataset.page;
                if (page) {
                    switchPage(page);
                }
            });
        });

        window.switchPage = switchPage;
        window.switchYear = switchYear;

            var input = lockInput.value.trim();
            if (input === correctPassword) {

                lockInput.focus();
            }

                unlockArchive();

        function doSearch() {
            var q = searchInput.value.trim();
            if (!q) {
                alert('请输入检索关键词');
                return;
            }
            var lowerQ = q.toLowerCase();

            // 如果报纸库未解锁，先提示
            if (lockScreen.style.display !== 'none') {
                alert('请先解锁报纸库');
                return;
            }

            if (lowerQ === '1923' || lowerQ === '陈砚秋') {
                switchPage('newspaper');
                switchYear('1923');
                searchInput.value = '';
                return;
            }
            if (lowerQ === '1956' || lowerQ === '王德福') {
                switchPage('newspaper');
                switchYear('1956');
                searchInput.value = '';
                return;

                switchYear('1979');

                return;

                return;

                switchYear('2012');
                searchInput.value = '';
                return;

                switchYear('2026');
                searchInput.value = '';
                return;
            }

            alert('未找到相关档案');
        }
